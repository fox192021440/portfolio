# 个人作品集 · 非标机械设计

李梓学 / Li Zixue —— 简单非标设备、工装夹具、钣金结构设计与出图。

线上地址：https://fox192021440.github.io/portfolio/

## 内容

- `index.html` —— 单页站点（案例 / 细节图 / 能力 / 合作方式）
- `assets/style.css` —— 深色工程风样式，无外部依赖
- `assets/app.js` —— 灯箱与大图查看、滚动渐显
- `img/` —— 1500px 展示图，`img/t/` —— 800px 缩略图

## 本地预览

直接双击 `index.html`，或：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 说明

- 纯静态页面，不加载任何 CDN 资源，国内可正常访问。
- 图片取自个人设计库，已压缩并脱敏，不含客户信息。
- 联系方式在 `index.html` 的 `#hire` 段落下，改成你自己的微信 / 邮箱即可。
